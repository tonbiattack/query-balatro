# Query Balatro 仕様書（SPEC）

作成日: 2026-11-16 / ステータス: 仕様段階

## 概要

Balatro系、クエリのパターンで役を作るスコアアタック。

ポーカー役の代わりにクエリのパターンで役を作る。断片カードを並べてクエリを組み、チップ×マルチでスコアを伸ばす。

## 共通前提
- プレイヤーが書けるのは原則 `SELECT` のみ。DBは読み取り専用接続で開く
- 実行制限: 1クエリ 100ms / 取得上限 100行（案ごとに調整可）
- 1プレイ完結型。セーブはラン単位のみ
- オンライン対戦・ランキングはMVP外
## 数値仕様
- 1ラン: 20分想定、アンティ8（各アンティに Small / Big / Boss）
- 1ブラインド: プレイ4回、ディスカード2回、手札8枚、並べられる断片は最大5枚
- ジョーカー枠: 5

## スコア式
- `スコア = チップ × マルチ`
- チップは返却行数の質、マルチは役の倍率

## 役の例
| 役 | 条件 | マルチ |
|---|---|---|
| ペア相当 | 単一 WHERE | ×2 |
| ストレート相当 | JOIN | ×4 |
| フルハウス相当 | ウィンドウ関数入り | ×6 |

## ジョーカー例
- NULL行を含むクエリはマルチ+4
- `LIKE` を使うたびチップ+30

## Bossの妨害
- データ側ではなくルール側を縛る（例: そのブラインド中 `ORDER BY` 禁止、重複行はスコア0）

## 勝敗条件
- 勝利: アンティ8のBossを突破
- 敗北: ブラインドの目標チップにプレイ回数内に届かない

## MVPで作らないもの
- ショップの経済バランス調整（MVPは報酬固定）
- オンラインランキング
